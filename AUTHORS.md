## How credit works here

* This file credits the people who own and build the project. It does **not** change git history.
* **Who wrote a given change** is recorded in the commit itself - see `git shortlog -sne` or the repository's *Insights -> Contributors* page.
  Set `git config user.name` / `user.email` correctly before your first commit so your commits are linked to your GitHub profile.
* Work done together: add `Co-authored-by: Full Name <verified-email>` at the end of the commit message.
* New contributors: add yourself in a pull request. See [CONTRIBUTING.md](CONTRIBUTING.md) and
  [docs/learning/07-teammates-and-access.md](docs/learning/07-teammates-and-access.md).
